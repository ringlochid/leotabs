# Neo 0.7.2: copy while dragging and consistent collection swapping

Saved tabs move by default. Hold Ctrl during a drop to copy; releasing Ctrl returns to moving. Cmd is also accepted. Shift remains available for selection and does not change a move into a copy. Saved-link/group drags advertise copyMove, and target dragover handlers select the matching cursor effect. Native feedback follows the [DataTransfer dropEffect contract](https://developer.mozilla.org/en-US/docs/Web/API/DataTransfer/dropEffect).

Copy works for one saved tab, multiple selected tabs, and whole groups. Copies have new IDs, keep URLs/titles/notes, and retain group metadata when copying groups or grouped selections. Dropping onto a group assigns the destination group; dropping onto a tab inserts before it. The same handlers support moves. Copying within a collection is supported. Open browser tabs continue to be saved as copies when dragged into the library. Collection-header dragging continues to reorder collections.

The shared collection search scope, including the website overlay, now displays Open collection and Swap to collection together. Open adds saved pages. Swap replaces the current window’s unpinned tabs and keeps the outgoing session in the existing session-retention mechanism. Library cards, collection menus and expanded collection views call the same shared swap function. The searchable Switch collection picker remains available for choosing whether to save the outgoing session.

An overlay swap closes the overlay and focuses a destination page. A library swap leaves the library visible. A test exposed the prior focus selection mistakenly considering an existing library tab as a destination; focus now chooses IDs actually opened or moved for the incoming collection.

Verification uses production library drop handlers and production overlay RPCs in a disposable real Chrome profile. Tests verify single-tab copies, selected copies into groups, whole-group copies, fresh IDs, retained notes, unchanged source data and normal moves. Unit tests also cover copied group metadata and same-collection insertion. Browser tests cover the overlay’s two adjacent actions, actual swap, pinned-tab preservation, overlay dismissal and destination focus, plus library swap and library focus. No everyday browser profile was used.

Final verification: 85 unit checks passed (`output/unit-0.7.2.txt`); 12 real-Chrome checks passed with zero exceptions (`output/chrome-1788675943106/results.json`). The screenshots were visually inspected. The checked archive is `output/neo-0.7.2.zip`, extracted and tested at `output/release-0.7.2-verified`.
