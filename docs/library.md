# Organize tabs and bookmarks by project

LeoTabs organizes saved browser tabs and bookmarks into collections, with spaces for broader areas of work. A collection keeps the links for one task together with groups and notes, so you can return to the work without searching through an unrelated list of bookmarks.

## Set up a project library

1. Create a space for an area such as Work, Study or Personal.
2. Open the pages for one task, then [save those tabs as a collection](saving-switching.md), or choose **New collection** to start empty.
3. Name the collection for the task, such as “Website redesign”, and add a note with the next step.
4. Group links by purpose: reference material, drafts and tools, for example. Drag additional open tabs into the collection as you find them.
5. When you return, choose **Open** to open its links alongside your current tabs, or **Switch** to make it the current project in that window.

For a Study space, keep an “Assignment research” collection separate from “Course administration”. Within research, groups can distinguish papers, datasets and your draft. Use a collection note for context such as “Compare the second paper's evaluation method next”.

## Bookmarks and open tabs

Open tabs are live browser pages. Collections hold saved links that can be reopened even after those pages are closed. [Import browser bookmarks](import-export.md) to organize existing saved links in the same library, or [move a OneTab or Toby export](migrate-tabs.md).

An import makes separate copies in LeoTabs. Changes to these copies do not continuously synchronize with Chrome or Edge bookmarks. You can export collections back to browser bookmarks, bookmark HTML or Markdown when you want to use them elsewhere. Collections do not automatically synchronize across devices; use a backup to move them between browser profiles.

## Spaces

Use the plus beside the space names to add a space. Select a space to see its collections. Rename a space inline; Enter saves and Escape cancels.

Drag a space name left or right. The insertion bar shows where it will land. Its menu also offers **Move left** and **Move right**, so dragging is not required. Undo can reverse a move.

To delete a space, open its menu and choose **Remove workspace**. It deletes that space and its saved collections, links and notes; open browser tabs stay open. Move collections to another space first if you want to keep them. If you remove the last space, a new empty one is created. Read the displayed counts before confirming.

## Collections

Choose **New collection** to start an empty one, or [save open tabs](saving-switching.md). Rename a collection inline. Use its menu to pin/unpin it, move it to another space, duplicate it, open it in a new window, view previous versions, group and sort, organise with AI, export or delete it.

Drag a collection header to reorder it. Watch the insertion bar before dropping. Pinning a collection keeps it easy to find; it is separate from pinning a browser tab.

The **Board view** and **List view** buttons change how collections are displayed. The collection chevron folds it, and **Expand** focuses that collection; **Restore** or **All collections** returns to the collection overview. **Show more** reveals links hidden by the preview limit. A short preview does not mean links were deleted.

## Links, groups and notes

Use **Add link** to save a URL manually. Each link can have a title and note. Clicking a saved link opens a fresh browser tab, including when found through search.

Use **Add group**, a group menu, selection actions or dragging to organise related saved links. The [groups guide](groups-selection.md) explains the difference between saved groups and live browser groups.

A collection note records what you were doing and what comes next. Edit the note in the collection; use **Delete note** to remove it. A small note indicator on a link can be hovered or focused to read, or clicked to keep the note visible.

## Colours and the current collection

Choose a collection colour from its options, including a custom colour. When a collection is active, its colour appears in the current-collection controls and lion icons. With no active collection, the lion uses its default amber colour.

Viewing a space or expanding a collection does not by itself make that collection current in your window. Use **Switch** to do that. See [saving and switching](saving-switching.md) for Auto-update.

Editing saved links or their grouping in a current collection can pause Auto-update. Check its **On / Paused** indicator before expecting later browsing changes to be saved.

Deleting a saved item can leave older recovery copies. For recovery and data removal, see [Undo and recovery](recovery.md) and [Settings and privacy](settings-privacy.md).
