# Security policy

Report suspected vulnerabilities privately to **support@ringlochid.me**, subject `LeoTabs security report`. Include the affected version/browser, reproduction, impact and a minimal synthetic example. Do not send live keys, a browser profile or a real collection backup. Ask first if sensitive material is needed.

Please allow investigation before publishing exploit details. This is independently maintained; no response-time guarantee, bounty or formal certification is offered. Security fixes target the latest Chrome Web Store release. Include whether you use the store version or an unpacked development copy in your report.

Browser metadata, screenshots, recovery snapshots and API credentials can be sensitive. Credentials are restricted to trusted extension contexts and excluded from backups, but are not encrypted by LeoTabs. Protect your browser profile and device. Revoke exposed keys at their provider even after deleting local copies.

Read the [privacy controls](docs/settings-privacy.md) and [privacy policy](extension/privacy.html) before connecting external services. Passing tests or secret scans does not guarantee an absence of vulnerabilities.
