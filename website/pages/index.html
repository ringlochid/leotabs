Q&A

Is LeoTabs free?

Yes. LeoTabs is free to use. Optional AI providers may charge for API usage.

Do I need to use AI?

No. Saving, switching, search, notes, file export and website grouping work without an AI connection.

Does LeoTabs organize Chrome bookmarks?

You can import browser bookmarks into LeoTabs collections, organize the saved links with groups and notes, and export them again. These are separate copies; LeoTabs does not continuously sync your browser's bookmark tree. Import and export bookmarks.

Can I move from OneTab or Toby?

Yes. LeoTabs imports OneTab text and supported Toby collections/cards JSON, as well as bookmark HTML. Review the import preview and keep your original export until you have checked the saved links. Move your saved tabs to LeoTabs.

Does it work in Microsoft Edge?

Yes. Install LeoTabs from the Chrome Web Store in a compatible version of Edge and allow extensions from other stores if prompted. Your library is local to that browser profile. Installation guide.

Can I take my collections with me?

Yes. Download backup JSON, bookmark HTML or Markdown. Back up before uninstalling or changing installations: local data is tied to the extension's identity in your browser. Read the backup guide.

What if I need to undo a change?

Undo and Recovery help restore saved work after supported actions. They cannot reverse a provider request or delete an exported Notion page. See what can be recovered.
