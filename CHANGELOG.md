# Changelog

## 0.13.1 — 9 September 2026

Available from the [Chrome Web Store](https://chromewebstore.google.com/detail/leotabs/heolckkdeandgagkiefggcneodniojhb).

- Save tabs into collections with groups and notes, organised into spaces.
- Open saved work or switch the current window to a collection, with optional Auto-update.
- Search open tabs and saved links, or use the visual tab switcher.
- Drag tabs, groups, collections and spaces with insertion feedback. Local sorting places ungrouped tabs before groups.
- Undo supported changes and recover saved work through Timeline and collection history.
- Export backup JSON, bookmark HTML or Markdown. AI organisation and Notion export are optional connections.

See the [user guide](docs/README.md) for installation and feature instructions.
